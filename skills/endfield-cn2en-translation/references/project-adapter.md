# 项目适配

按当前任务补充以下信息，以便选择译法、组织输出并核对资源。

| 项目字段 | 用途 |
| --- | --- |
| 原文与输出目录 | 定位文件及相对资源路径 |
| 语料版本与时间 | 限定游戏名称和研究结论 |
| 本地词表路径 | 提供有权使用的数据，按数据说明加载 |
| 项目术语与作者署名 | 保存局部定义、适用页面及选定写法 |
| 发布规则 | 指定来源署名、权限、隐私处理和资源要求 |
| 输出格式与检查方法 | 验证当前文档的公式、锚点与资源 |

更新已有译文时，对照旧源、新源与旧译文，逐项处理新增、修改、删除和移动。仅复用有可信语义审核记录的未改译文；文件哈希或结构检查通过不能代替语义审核。

资源和图片是否保留、脱敏或重绘由当前任务规定。项目术语可以补充内置词表，但不能仅凭局部约定覆盖游戏正式名称的证据；使用范围随文档记录。
