# 玩家黑话与攻略简称

本表只记录社区攻略、蓝图说明和讨论中观察到的玩家用语。它不是官方本地化表，也不能替代 `official-names.md`、`game-terms.md` 或用户已确认的 `community-aliases.md`。

状态含义：

- `community-observed`：至少在公开攻略或讨论中实际出现，可作为语境线索。
- `context-required`：必须结合配方、版本、设备或页面上下文，不能全局替换。
- `provisional`：只有单篇或少量语料，暂不固定英文。
- `document-only`：只在特定语料或某作者的局部定义中成立。

| 玩家用语 | 语境读法 | 英译建议 | 状态 |
| --- | --- | --- | --- |
| 基建 | 集成工业系统/工厂布局的玩家简称 | `factory setup` 或 `AIC setup`；正式系统名仍查官方表 | community-observed, context-required |
| 毕业基建、毕业产线 | 当前版本资源、产能和解锁基本完成的终局布局 | `endgame factory layout` / `endgame production line` | community-observed, version-bound |
| 临时基建 | 开矿或升级前的过渡布局 | `temporary factory setup` / `interim layout` | community-observed |
| 抄作业 | 直接照搬别人的蓝图或布局 | `copy a build` / `follow a shared blueprint` | community-observed |
| 蓝图、蓝图码、分享码 | 可复制的产线布局及其代码 | `blueprint`, `blueprint code`, `share code` | community-observed |
| 模块化、分产线、拼接 | 拆分、组合大型产线 | `modular layout`, `sub-line`, `assemble modules` | community-observed |
| 总线 | 多条产线共用的主运输/资源通道 | `main bus` | community-observed, context-required |
| 存取线、存货口 | 仓库输入/取货方向的玩家叫法 | 按方向写 `storage line`, `Depot Loader input`, `pickup port` | context-required |
| 暗管、多暗管 | 流体/气体地下管线或并联管线 | `underground pipe`; 多暗管暂译并保留定义 | community-observed, provisional |
| 拉矿、拉水、拉线 | 把资源或流体接入基地 | `route the ore/water` / `run a line` | community-observed |
| 满速、半速、拉满 | 达到设计吞吐或部分吞吐 | `full-rate`, `half-rate`, `maxed out` | community-observed, context-required |
| 爆仓 | 仓库或缓存达到容量上限 | `storage overflow` / `product storage overflow` | community-observed, context-required |
| 堵停产、产线卡死、淤堵 | 缓存、废液或出口阻塞导致停产 | `the line backs up`, `blocked`, `production stops` | community-observed, context-required |
| 设备睡觉、反应池睡觉 | 玩家拟人化地说设备处于闲置/无输入状态 | `the machine is idle`; 明确缺料时 `starved of input` | community-observed |
| 断联的水管 | 水管未连接或无有效供水 | `disconnected pipe` / `unconnected water line` | community-observed |
| 反应池卡住 | 反应池内部余料占位，阻塞其他通路 | `reaction tank blockage` / `the reaction tank is blocked` | community-observed, context-required |
| 中容、高容、低容 | 电池容量等级简称 | `medium-capacity`, `high-capacity`, `low-capacity`; 正式物品名查游戏表 | community-observed, version-bound |
| 纯售卖电池 | 生产后主要用于出售的电池 | `sell-only battery line` | community-observed |
| 蓝药、紫药、紫胶囊 | 按颜色、用途或容器称呼的药品简称 | 回到配方/物品 ID；首次可写 `community shorthand` | community-observed, context-required |
| 设备爆仓自救、空仓换线机、单刀双掷 | 玩家用反应池和库存条件实现自动切换的方案名 | 保留中文方案名并附机制解释；`SPDT automatic switch` 仅作暂译 | provisional, document-only |
| 通马桶 | 清理堵塞/疏通产线的戏称 | 正文写 `unclog the line`，不当作设备名 | provisional |
| 尿分叉法 | 单篇帖子中的戏称或疑似笔误 | 保留中文并标注作者用语，不造正式英文名 | provisional, document-only |

“红矿”“铜药”“小药”“气矿”“双口”等历史别名候选见 [community-aliases.md](community-aliases.md)。新文档须重新匹配上下文；历史用户确认不构成所有作者的通用定义。本表没有逐条公开引文，保留原有观察状态，不宣称已在本轮重新核验或形成社区共识。

维护时记录来源、版本和上下文。单篇帖子或视频标题不能把词条升级为官方名称；至少有多个独立语境且和游戏数据一致，才可考虑加入长期别名表。
