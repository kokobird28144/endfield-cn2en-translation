# 术语背景主题索引

本文件解释生产术语表中的 C1–C12 背景主题编号。翻译时以当前原文及其局部定义为准。

需要补充背景时，在当前语料中按主题检索相邻定义。

| 编号 | 主题 | 查阅用途 |
| --- | --- | --- |
| C1 | 生产术语表 | 物料、节点、上下游、溢流、加压 |
| C2 | 阻塞生产 | 阻塞信号与智能切换 |
| C3 | 阻塞分类 | 切换型/平衡型阻塞，平均流量视角 |
| C4 | 阻塞端与流通端 | 分流/汇流的控制方向 |
| C5 | 配平与自适应 | 配平、自适应、价值优化的区别 |
| C6 | 理想系统 | 有向多重图、流量守恒、MILP/SMT |
| C7 | 波动与均匀度 | 计数树、符号与词义统一 |
| C8 | 历史物流模型 | 阻尼、物流线、连接顺序；注意理论时效性 |
| C9 | 反应缓存与物流相位 | 完成缓存、落地/启动时序、共享容量、观察与推论边界 |
